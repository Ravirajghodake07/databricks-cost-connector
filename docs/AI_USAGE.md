# AI usage

This project used AI-assisted development. ChatGPT and Cursor were used for repository and code review, implementation assistance, debugging, test design, documentation, and checking the work against the assessment requirements.

The developer reviewed and validated the generated changes, ran the automated tests, and performed the live Databricks collection against the assessment workspace.

AI tools did not independently authenticate to Databricks or run the live collection. Credentials and live workspace access remained under the developer’s control.
